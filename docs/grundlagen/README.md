# Technische Grundlagen

Plex und Jellyfin übernehmen die Verwaltung deiner Medien. Wie gut die Wiedergabe funktioniert, hängt aber auch von Speicher, Dateinamen, Netzwerk und unterstützten Formaten ab.

## Vom Speicher zur Wiedergabe

Plane zuerst genug Platz für Filme und Serien. Eine einheitliche Ordnerstruktur hilft anschließend, diese Dateien automatisch den richtigen Titeln zuzuordnen.

Bei der Wiedergabe sind drei Begriffe wichtig:

| Begriff | Bedeutung für deinen Server |
|---|---|
| Direct Play | Der Client kann die Datei unverändert abspielen; der Server hat wenig Rechenarbeit. |
| Transcoding | Der Server wandelt Bild oder Ton während der Wiedergabe um. Das benötigt zusätzliche Rechenleistung. |
| Hardware-Transcoding | Spezialisierte Videoeinheiten übernehmen unterstützte Umwandlungen und entlasten den Prozessor. |

Diese Grundlagen gelten für beide Programme und beide Hostingvarianten. Sie helfen dir einzuschätzen, ob dein vorhandener Rechner ausreicht und wo ein Engpass entstehen kann.
