# Jellyfin

Jellyfin ist eine kostenlose Open-Source-Software für deinen Medienserver. Du betreibst den Server selbst und verwaltest die Benutzerkonten lokal. Ein zentrales Jellyfin-Konto beim Anbieter ist dafür nicht nötig. Das Projekt beschreibt diesen Ansatz in seiner [offiziellen Dokumentation](https://jellyfin.org/docs/).

## Stärken

- Kostenlose Medienserver-Software mit offenem Quellcode.
- Vollständig selbst gehostet und mit hoher Kontrolle über den Betrieb.
- Lokale Benutzerverwaltung auf deinem Server.
- Gut für selbst verwaltete Linux-Systeme und Homeserver geeignet.

Jellyfin ist nicht auf Linux oder den Standort zu Hause beschränkt. Auch ein geeigneter Dedicated Server kann deine Bibliothek bereitstellen.

## Was du berücksichtigen solltest

Je nach System erfordert die Einrichtung mehr eigene Konfiguration. Auch Auswahl und Komfort der Clients hängen von deiner Plattform ab. Prüfe deshalb, ob für deine Wiedergabegeräte passende Apps verfügbar sind.

Die Software ist kostenlos; Hardware, Strom oder Servermiete verursachen trotzdem Kosten. Die Abwägung gegenüber Plex findest du im [Direktvergleich](../erste-schritte/plex-oder-jellyfin.md).
