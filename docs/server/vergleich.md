# Homeserver oder Dedicated Server?

Beide Varianten können Plex oder Jellyfin betreiben. Der wichtigste Unterschied ist, wo Hardware und Daten liegen und wer den physischen Betrieb übernimmt.

| Thema | Homeserver / NAS | Dedicated Server |
|---|---|---|
| Hardware | Gehört dir | Gemietet |
| Standort | Zu Hause | Rechenzentrum |
| Anfangskosten | Meist höher, sofern noch keine Hardware vorhanden ist | Meist niedriger, mögliche Einrichtungsgebühr |
| Laufende Kosten | Strom, Wartung und Ersatzteile | Servermiete, gegebenenfalls Zusatzkosten |
| Speicher | Im Rahmen der Hardware selbst erweiterbar | Vom Angebot des Anbieters abhängig |
| Streaming zu Hause | Direkt über das Heimnetz | Über das Internet |
| Remote-Streaming | Vom eigenen Upload und der Erreichbarkeit abhängig | Rechenzentrumsanbindung, abhängig vom Vertrag |
| Physische Kontrolle | Hoch | Gering |
| Hardwarewartung | Deine Aufgabe | Aufgabe des Anbieters |
| Softwarewartung | Deine Aufgabe | Bei selbst verwalteten Servern deine Aufgabe |

## So ordnest du die Varianten ein

Für eine große, langfristige Sammlung und häufiges Streaming zu Hause kann eigene Hardware attraktiv sein. Du hast direkten Zugriff auf die Datenträger und kannst den Ausbau selbst planen.

Ein Dedicated Server kann passen, wenn du vor allem remote zugreifst oder ohnehin Infrastruktur im Rechenzentrum betreibst. Dafür musst du laufende Miete und Speicherpreise einplanen.

Für die konkrete Dimensionierung fehlen jetzt noch zwei Dinge: der Platzbedarf deiner Sammlung und die Rechenarbeit bei der Wiedergabe. Die nächsten Kapitel erklären beides, bevor es an die Einrichtung geht.
