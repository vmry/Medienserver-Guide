# Server und Hosting

**Hosting** bedeutet hier, den Rechner und die Umgebung für Plex oder Jellyfin bereitzustellen. Die Software muss auf einem Server laufen, der beim Streaming erreichbar ist.

In diesem Guide gibt es zwei Varianten:

| Variante | Einfach erklärt |
|---|---|
| Homeserver / NAS | Hardware und Datenträger stehen bei dir zu Hause. Ein NAS ist ein auf Dateispeicherung spezialisierter Server. |
| Dedicated Server | Du mietest einen vollständigen physischen Server in einem Rechenzentrum. |

## Was deine Entscheidung beeinflusst

- **Standort der Zuschauer:** Schaust du vor allem im Heimnetz oder häufig unterwegs?
- **Speicher:** Wie groß ist deine Sammlung, und wie schnell wächst sie?
- **Kosten:** Möchtest du Hardware kaufen oder monatlich mieten?
- **Betrieb:** Wer kümmert sich um Hardware, Betriebssystem und Updates?

Der Standort allein sagt noch wenig über die benötigte Rechenleistung aus. Entscheidend ist auch, ob deine Clients die Dateien direkt wiedergeben oder der Server sie umwandeln muss. Die [technischen Grundlagen](../grundlagen/README.md) erklären diesen Zusammenhang.
