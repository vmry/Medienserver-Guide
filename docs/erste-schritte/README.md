# Erste Schritte

Für deinen ersten Medienserver reichen vier Bausteine:

| Baustein | Aufgabe |
|---|---|
| Server | Ein Rechner, auf dem die Medienserver-Software läuft. |
| Speicher | Festplatten oder andere Datenträger für deine Filme und Serien. |
| Plex oder Jellyfin | Die Software verwaltet deine Bibliothek und stellt sie zur Wiedergabe bereit. |
| Client | Eine App oder ein Browser auf dem Gerät, mit dem du schaust. |

Server und Client sind über ein Netzwerk verbunden. Der Server muss eingeschaltet und erreichbar sein, solange du streamen möchtest. **Streaming** heißt, dass das Wiedergabegerät die Daten während der Wiedergabe empfängt.

## Was reicht zum Einstieg?

Du brauchst nicht sofort einen Serverschrank oder Dutzende Festplatten. Ein kleiner Homeserver kann bereits ausreichen. Auch ein vorhandener PC kann helfen, die Komponenten und ihre Aufgaben kennenzulernen.

Entscheidend sind zunächst deine Dateien, deine Wiedergabegeräte und die Frage, ob du zu Hause oder auch unterwegs schauen möchtest. Später kannst du Speicher und Hardware schrittweise erweitern.

Im nächsten Kapitel siehst du, [wie die Bausteine zusammenarbeiten](wie-funktioniert-ein-medienserver.md). Danach folgt der [Vergleich von Plex und Jellyfin](plex-oder-jellyfin.md).
